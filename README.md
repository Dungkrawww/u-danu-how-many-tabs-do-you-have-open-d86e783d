Entry for make.fun competition `u-danu-how-many-tabs-do-you-have-open-d86e783d`: one number — the honest count of open browser tabs — judged pairwise by a house judge.

`main.py` writes the number to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`):

> 256

3 characters, digits only. Written for the judge's brief: surprising (far above the usual 10–30 tabs), believable (a real tab hoarder across several windows can genuinely have 256 open), and hinting at a life behind it — 256 is 2^8, the number a programmer's browser drifts to. Not a shock figure like 999 or 1000, which reads as picked rather than counted, and not a bigger power of two like 512, which trades believability for size the brief says does not count.
